QuantReplay QA Automation: framework layers

Read from top to bottom: each layer uses only the layers below it, never a layer above (one exception: models use the FIX enums from fix/tags.py). For every layer: what it is for, what is inside, and what it must never do.

Why layers can be replaced

  • Services declare what they need as a Protocol (Session, Http, Db), not a concrete class.
  • conftest plugs in the real FixSession, HttpClient, DbClient.
  • Another FIX engine or DB driver: change transport + conftest. Tests stay the same.
  • One model (Listing) for REST and DB: compared field by field in one call.
